# Token Launch Radar

A radar of the protocols that still record no token, ranked by what their
launch would be worth if their record stayed as it is. Built for make.fun's
[Build the best token launch radar](https://make.fun/bounty/token-radar-01)
bounty.

The program reads the sealed snapshot of every protocol DefiLlama tracks and
writes a board, a dashboard, its screenshots and the dossier the judge reads:

- **board.json** — every launch candidate ranked by an implied value, the whole
  watchlist in, a farm plan on every row
- **dashboard/** — the board a reader can use: sortable, filterable, a detail
  view per protocol, the live-token calibration set beside the board, and the
  method with this run's own multiples
- **screenshots/** — the board, a detail view, a filtered view
- **dossier.json** — `buildDossier` of the two above

## The model

`implied_value_usd = tvl × multiple × growth × maturity × breadth`

- **multiple** — the market's own pricing: per category, the median mcap/TVL of
  the snapshot's live tokens, shrunk toward the snapshot-wide median by three
  pseudo-peers, clamped ×0.05–×2.3
- **growth** — the 7-day TVL change on a saturating curve, ×0.7–×1.3
- **maturity** — days on the record with no token, ×0.7→×1.0 over two years
  and easing after four
- **breadth** — chains served, +4% each to a fifth extra chain

No protocol is special-cased: one function scores every row, the same rules
write every farm plan, and the same logic runs in the page, so the dashboard
and board.json always agree. The implied value is this entry's own claim, not a
prediction and not make.fun's.

## Run it

Node 22.18 or later, the standard library only, nothing to install:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input devdata/snapshot.json
node tools/check.ts devdata/snapshot.json out   # the gate's seven rows, locally
```

The sealed snapshot sits at `/input/snapshot.json` when the grader runs
`main.ts`; `devdata/snapshot.json` is a development fixture.

## Layout

- `main.ts` — the entrypoint: reads the snapshot, writes board, dashboard,
  screenshots, dossier
- `lib/model.ts` — the value model, the watchlist rule, the farm plans
- `dashboard/` — index.html, app.css, app.js, zz-data.js ( regenerated by
  `main.ts` every run)
- `vendor/makefun-board.ts` — make.fun's dossier library, copied unchanged
  from the kit
- `tools/check.ts` — the gate's checks, run locally
