How the radar scores

implied value = TVL × category multiple × growth × age × chains

  • Category multiple — the median market-cap-per-TVL of the tokenized protocols in the same category (five or more of them, else the global median), clamped to 0.02–2.00. It answers: what does the market pay per dollar of TVL for protocols like this one that already trade?
  • Growth — 1 + the 7-day TVL change, capped at ±20 points. A week’s move is noisy, so it can only nudge the value.
  • Age — 0.80 + 0.20 × min(days listed / 365, 1). A protocol that has run a year with no token has survived; a new listing has not. Age can only reward survival, never inflate without limit.
  • Chains — 1 + 0.05 per extra chain, up to four. Wider distribution is worth a little, not a lot.
  • Excluded before ranking — bridges, liquid staking and restaking, CEX products, wrapped or staked products, versioned names and exchange-named products. Each is a product of a token that already trades, so none is a launch still to come. —

The result is clamped to 0.01–3.00× TVL and rounded to whole dollars. The implied value is this entry’s own claim from the snapshot’s figures — not a prediction that a token will be issued, or of what one would trade at. Every protocol here is described as recording no token, never as having none: the snapshot is DefiLlama’s record, not proof.
